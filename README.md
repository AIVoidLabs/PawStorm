# PawStorm

**A fast, cheerful 3D platformer about a young cat, a stolen storm and a very silly dog scientist.**

You are **Pati**, a quick-witted street cat. A mysterious energy called the **Storm Core** has swept over the city and the street cats are vanishing. Collect the scattered Core shards, beat the villains and bring everyone home.

Built with **Godot 4 (.NET / C#)**. PC (Windows 64-bit) only for now.

> Status: playable prototype (v0.2.0). Nine levels, two boss fights, no save system yet.

## Features

- **Momentum-based movement**: build speed, use slopes, run full vertical loops.
- **Pati Sprint** (spin dash): hold Shift to charge a 3-segment bar, release to launch.
- **Pounce**: a homing attack that locks onto targets, enemies and even boss projectiles.
- **Rail grinding**, **wall climbing** (on climbable walls) with wall jumps, and **Air Twist** (double jump).
- **Fish** as the collectible; when hurt you drop fish before you lose a life. **9 Lives**, with a Game Over screen.
- **Nine levels** across 7 regions and 2 boss arenas (see below), each with its own look, music and ambience.
- Cartoon look: toon shading and ink outlines. Models, music and sound effects are generated by scripts in this repo.

## Getting started

### Requirements

- [Godot 4.7.2 **.NET** (mono)](https://godotengine.org/download)
- .NET SDK 8 or newer (the project targets `net8.0`)

### Run

```bash
dotnet build
godot --path . --editor    # then press Play (F5); the main scene is the title menu
```

`Godot` here is the .NET build of the editor. On Windows use the full path of `Godot_v4.7.2-stable_mono_win64.exe`.

### Export (Windows)

Install the 4.7.2 mono export templates (Editor > Manage Export Templates), then:

```powershell
powershell -File Docs/tools/release.ps1 -Version 0.2.0
```

This builds, exports `build/PawStorm.exe` (with the `data_PawStorm_windows_x86_64` folder) and zips both into `release/`. Code signing is optional: see `Docs/tools/sign_build.ps1` (the certificate comes from environment variables, nothing is stored in the repo).

## Project layout

```
Scripts/{Player,Camera,Enemies,UI,Core}   C# game code (state machine, boss AI, HUD, audio, level helpers)
Scenes/{Levels,Player,Props,UI}           Scenes (Levels 2-9 are generated, see below)
Resources/PlayerStats.tres                All movement/physics constants (tweak feel here)
Art/{Models,Materials,Textures,Icon}      .glb models, toon/outline shaders, menu backgrounds
Audio/                                    Music, ambience and sound effects (.wav)
Docs/                                     Game design document and tools
```

Key ideas:

- The player is a `CharacterBody3D` with a state machine (Idle, Run, Jump, Fall, Charge, Spin, Pounce, Grind, WallClimb, Loop, Hurt). No physics constants are hard-coded: they live in `PlayerStats.tres`.
- Levels are greyboxes (CSG collision) that a `LevelDresser` covers with modelled tiles at runtime; `BarrierLine` adds railings with invisible side walls.

## Generated content and tools

Most art and sound are produced by scripts, so they can be changed and regenerated. Generated files are committed, so you only need these tools if you want to modify them.

| Tool | Needs | Output |
|---|---|---|
| `Docs/tools/blender/make_models.py` | Blender 5.x | Rigged, animated characters: Pati, enemies, bosses, fish |
| `Docs/tools/blender/make_environment.py` | Blender 5.x | Tiles, railings and set-dressing props (`Art/Models/Env`) |
| `Docs/tools/blender/make_icon.py` | Blender 5.x | Game icon |
| `Docs/tools/audio/make_audio.py` | Blender's Python (numpy) | Music loops, ambience, sound effects |
| `Docs/tools/gen_levels.ps1` | PowerShell | Levels 2-9 (`Scenes/Levels`) |
| `Docs/tools/capture_scene.gd` | Godot | Menu background screenshots |

Example:

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python Docs/tools/blender/make_models.py
```

Note: `gen_levels.ps1` overwrites levels 2-9 when run. Level 1 is hand-edited.
